# Portfolio Summary

## Problem
Customer teams need one view of observed churn signals, customer value, model risk, revenue exposure, and transparent retention actions.

## Solution
CustomerIQ combines a React/Vite SaaS interface, FastAPI services, PostgreSQL storage, reproducible analytics, versioned churn artifacts, and a retention action workflow.

## Evidence
The imported Hugging Face source contains 500 records. The project reports actual source quality, observed churn labels, MRR, segmentation proxies, saved model evaluation artifacts, and explicit limitations.

## Limitations
The source lacks event dates and transaction history, so true monthly trends and cohort retention are unavailable. Native model inference is blocked in the current Windows environment by Application Control. Authentication is planned, not implemented.
